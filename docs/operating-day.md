# 営業日・収支・保存

保存キー `bakery_web_v1` を維持し、現在はv5で営業・スタッフ・仕事・客・収支を同時保存します。v1〜v4も読み込み、既存の家具・所持金・パンを維持します。

## 営業日

開店前は09:00のまま、スタッフが仕入れ・製造・焼成・回収・陳列を実際に行います。製造中・運搬中を含む準備パンは合計15個まで。仕入れは5個分30円で、入荷時に支払い、製造で二重に払わないようにします。棚在庫は全棚共通12個です。

調理台・オーブン・棚・レジが通行可能な位置にあれば開店できます。レジには客とスタッフのため周囲2マス以上の空きが必要です。営業中は09:00〜18:00を進め、一時停止すると移動・作業・焼成・客の会計も停止します。

18:00は営業終了。新しい仕事と購入を停止し、未会計の商品を返却して退店へ切り替えます。締めは開店前に受け付けず、連打で日が飛ばないようにします。締めで当日の結果を保存して翌日09:00へ移り、収支を表示します。

材料・パン・家具・所持金・焼成残りは持ち越します。未投入の生地は材料へ、スタッフの運搬中のパンは完成品へ戻し、翌日の作業を再開します。売上・販売数・来客間隔・当日の費用はリセットし、前日の結果を維持します。

## 収支

売上欄のタップで売上・材料費・営業利益・設備購入・撤去返金・所持金増減・所持金・販売数・来客数を表示。翌日の開店前は前日結果、開店後は本日結果を表示します。

営業利益は売上から当日仕入れた材料費を引いた簡易集計で、設備投資を含みません。所持金の増減は営業利益から設備購入を引き、撤去返金を足した額です。旧セーブに記録のない費用を推測せず、その日の利益は未確定として翌日から通常集計します。

## 保存と確認

設備編集、指示・担当・見た目変更、作業の確定、マス到着、営業進行、開始・停止・締め・初期化で保存します。ページ非表示・退出時にも保存し、閉じた間の時間を自動進行しません。保存失敗時は通知します。家具の選択・ドラッグ候補は保存しません。

確認した一連の仕事と3営業日、旧データ、途中保存、資金不足、早締め、初期化、スマホ相当表示の結果は `mvp-status.md` と `tools/tests/README.md` に記録しています。スマホ実機は未検証です。
