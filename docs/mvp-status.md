# 改訂MVPの完了範囲

店主＋ノアの基礎モデルと個別指示を含め、仕入れ → 製造 → 陳列 → 客の選択 → レジ会計 → 締め → 再投資が実際の移動・作業と連動するところまで実装しました。自由配置と既存セーブを維持しています。

## 実装済み

- 初期10×10、最大16×16タイル、家具6種類、複数マス、90度回転、自由配置・ドラッグ移動・撤去、衝突・通路判定。本体選択時は55%の不透明度で表示。
- 店主・ノアの固定カメラの基礎モデル、4方向、待機・歩行・簡単な作業表現。1×1占有と見た目を分離し、高さ・太さ・全体サイズを変更可能。
- 個別の担当設定・優先作業指示。初期設定は店主が製造、ノアが陳列・会計で、材料不足時には仕入れも行う。
- 材料入荷時の支払い、調理台での仕込み、オーブンへの運搬・焼成・回収、棚への実際の運搬・陳列。
- 客は棚で1個確保してレジへ歩き、スタッフの会計完了時に120円の売上を一度だけ確定。客とスタッフのレジ周囲2マスを必要とする。
- 09:00〜18:00、開店前の実作業と仕込み上限15個、棚容量12個、一時停止、締め、翌日、在庫・焼成の持ち越し。
- 日別の売上・材料費・営業利益・設備投資・撤去返金・所持金増減。売上欄タップと締めで詳細表示。
- スタッフ・仕事・運搬品・客の確保品・途中位置・サイズ・営業・収支を同時保存。非表示中・ブラウザー終了後は進行しない。

床3素材・壁3素材・出入口・横と奥への増築を追加しました。床と壁は独立管理し、壁の通行判定・設備の作業面・増築時の途中作業を維持します。詳細は `interior-and-expansion.md`。

詳細は `staff-workflow.md`。完成目標は `mvp-definition.md`。

営業利益は「売上 − 当日仕入れた材料費」の簡易集計です。在庫評価・減価償却・家賃・人件費はありません。設備購入・内装費・増築費・撤去返金は所持金増減に含め、営業利益と区別します。

## セーブ互換性

保存キーは `bakery_web_v1` のまま、形式はv6。v1〜v5の家具・所持金・パン・営業を維持し、旧焼成・購入済み客を再課金しません。記録のない旧費用から利益を推測せず、未確定として翌日から通常集計します。
