# 木の描画順と増築時の除去

2026-10-20。木が店舗の床で切れる指摘を修正。素材自体は個別の透明画像だったが、地面の背景キャッシュへ木も描いていたため、後から描いた床が樹冠を削っていた。

木は地面キャッシュから分離し、床を描き終えた後、家具・壁・人物と同じ奥行き順へ独立した景観パーツとして登録する。木の画像や世界観は維持。床の多角形で木を切り抜いたり、木を避けて床の形状を変える処理はしない。

配置は元の12×12店舗の正面を基準にした固定敷地座標。横の増築に応じて木を外へ動かす旧配置を廃止した。奥行の増築は店全体を座標上でずらす既存仕様に合わせ、木も正面からの距離を維持する。樹冠・根元の範囲と余裕幅が店舗に重なる木は、パーツごと描画対象から除去する。新しい木の購入・伐採費・外の配置機能・保存項目は追加しない。

- `exterior.js`：`treeLot` が固定配置、`trees(width,height)` が増築後の対象を導出、`drawTree` が個別画像を描画。
- `index.html`：床の後のsceneへ木を登録し、接地位置の奥行きで並べる。
- 花・低木・地面は引き続き背景キャッシュ。外側にある床・壁・道路の仕様は維持。

`node tools/tests/tree-scenery.cjs`：木が全床より後に各1回描かれること、描画時の状態非変更、実際の有料増築（横2回・奥2回）、木が復活しないこと、残る木の敷地位置、保存・再読込、増築後の180分6件販売を確認。12×12で8本 → 14×12で6本 → 16×12で6本 → 16×14で5本 → 16×16で4本。
