# 壁紙30種類・床材30種類

2026-10-20。日本の実在メーカーの公式カタログで柄分類・素材感を調べ、絵本のパン屋に合わせた独自の油彩素材として制作。メーカーの実商品・品番の再現ではなく、一般的な木目・織物・花柄・石目などを取り入れたゲーム内コレクション。

[60種類の見本と店内コーディネート](review/index.html)。[PR #15](https://github.com/yyvape-dev/bakery-simulator/pull/15) をmainへ取り込み（`2e7fc19`）、公開済み。床・壁とも既存3種類を残して合計30種類（追加27種類ずつ、生成素材54枚）。既存の内装・人物・動物客・扉・木の独立描画を維持する。

## 生成・再構築・描画

`catalog.json` が60種類の定義と生成プロンプト。`floor-atlas-0/1.png` と `wall-atlas-0/1.png` は、5列×3行で制作した生成元4枚。元アトラスの既存素材6セルは使わず、従来の素材を保持する。

```
node tools/art/pack_interior_catalog.cjs
```

54枚のWebPと `assets/interior/catalog/manifest.json` を出力し、`interior.js` のレジストリも同じ定義から更新する。床は256×256の反転した四象限で縁を連続させ、壁は512×256で横だけ反転し、植物・腰壁の上下を保つ。壁は4区画にまたがる横柄を共有し、高さ方向は壁全体に合わせる。

ヘリンボーン3色は生成した木目を個々の板に使い、長さ3：幅1の板2本のL形を敷き詰め、世界座標に沿った反復パターンとして描く。タイルの端で模様の原点を戻さず、複数マスの床に連続する。世界座標の縦横2マスで位相が一致するため、奥への増築による2マス移設でも既存の床柄を保つ。画像欠損時も板の形と代替色を残す。

## 操作・保存

既存の店づくり → 床／壁で選ぶ。6つの柄グループで絞り込みでき、見本のリストだけをスクロールする。店内と「戻る」は小画面でも維持する。選択だけでは課金せず、実際に貼るマス・区画数だけ従来の費用処理で支払う。同じ材質を重ねても課金しない。

材質IDは既存の `room.floors`／`room.walls` に保存し、保存バージョンは7のまま。既存3種類のID、価格、描画、旧セーブの店舗配置は維持。レジストリは `interior.js` 内に含み、画像が読めなくても材質IDを復元できる。扉の開口と通行判定、素材変更・撤去返金・増築の処理は従来どおり。
