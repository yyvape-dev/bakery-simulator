# 商品UIの厚塗り素材

2026-10-14。画像生成で現在の商品画面に必要な17点を作成。

- 材料6点：小麦粉、水、ミルク、バター、チョコ、チーズ。
- 飾り3点：木のプレート、緑のクロス、花を添えたクリーム皿。
- パン8点：水／ミルク生地 × 具材なし／バター／チョコ／チーズ。

「具材なし」「飾りなし」は空の器と点線のSVG記号を残し、未選択・欠品と区別する。

## 制作

既存のSVG雛形を画像として描画し、形状と構図の参照に使用。既存家具の oven.webp の厚塗りを基に承認済みバターを作成し、材料と飾りの共通画風へ展開。パンは定番パンを先に作成し、これを参照して7派生を生成。各呼び出しのプロンプトは product-prompts.json に保存。

元PNGは1448×1086のRGBAで、作業用 /workspace/generated_images と /workspace/bakery-art-review/painted に保管。配信は透過を保った最大640×480のWebP。全17点で約544KB。画風の変更と物体の描き直しは image_gen を使い、WebPへの書き出し・縮小は配信用の処理として行う。

## 表示

assets/products/manifest.json と assets/product-art.js の BakeryProductArt がパスと描画位置を管理。元画像の見える範囲を雛形の見える範囲へ合わせる表示座標を使い、画像自体の輪郭を変形しない。パンと飾りは独立画像で、皿→パンの順に重ねる。完成画面、選択カード、商品一覧へ同じ素材を使用。

画像が届くまで元のSVGを表示し、読み込み成功時に厚塗り画像へ切り替える。読み込み失敗時もSVGで選択を続けられる。PNG/WebPのアルファ、見切れ、ファイルサイズを検査し、8パン×4飾り＝32通りを確認する。

経営数値、製造時間、占有、保存形式7は変更しない。開発は即時完了し、通常のパン製造・焼成・陳列・会計をスタッフが行う。新しい素材は商品画面用で、床・壁・家具・スタッフの描画には適用しない。

## 床・壁・家具の次工程

床はタイル境界と模様の連続性、壁は2方向・出入口・高さ、家具は4方向・複数マス占有・接地アンカー・重なり順を確認する必要がある。家具は固定モデルとカメラから各方向の雛形を作成し、画風の仕上げ後もゲームの投影・衝突・回転を変更せずに確認する。今回の画像生成だけで家具の正確な投影を保証しない。

## 検証方法

tools/tests/product-art.cjs で17画像の透過・余白・容量、全レシピ／材料の表示、32通りの重ね合わせ、選択状態、画像表示時のデータ不変、保存・再読込、画像読み込み失敗時の代替表示、320×568と844×390のレイアウトを確認。products / experience / workflow と合わせ開発・完了画面・価格・収支・通常営業も確認する。

公開ファイルを取得してローカル版との一致を確認し、取得した配信ファイルをChromiumで操作する。スマホ実機と直接のHTTPSブラウザー操作は未検証。
