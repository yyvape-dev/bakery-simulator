# 油彩の絵本の外景

2026-10-20。単調な反復草地と現代的な道路設備から、重ね塗りの草原、リンゴと白樺の木立、草花、苔石のある童話の景色へ改修。地面3素材と外景4素材を画像生成し、筆跡・不均一な輪郭・セージと黄土の色調をそろえた。村の石の小道、木柵、ランタンを組み合わせる。

店舗は従来どおり独立した床・壁・家具・人物。風景は店外に配置し、増築時には店舗サイズに追従する。経路・設備・保存・所持金・動物客8種は変更しない。扉3種も維持。外景の配置は決定的で、再描画でランダムに変わらない。地面と植生は既存の画角キャッシュへ描き、ズーム・パン・画面寸法・増築・画像読込で再構築する。

`terrain-atlas.png`：3列の草地・砂・石畳。`scenery-atlas.png`：上段に木2種（画像高さ62%）、下段に花・苔石。画像生成後に背景除去を依頼し、透明素材としてパック。元の生成画像は別途保持する。

再構築：`node tools/art/pack_landscape.cjs`。地面は反転した4面を結合し、繰り返しの境界を連続させる。実行時は `assets/exterior/*.webp`。生成素材は装飾用で、道路上の歩行や外への設備配置は未実装。

[変更前後と各画面](review/index.html)。検証：`node tools/tests/exterior.cjs`（3扉・保存・配置／資金維持・3画面・ズーム45/300%・180分営業）、`workflow.cjs`、`storybook-ui.cjs`。
