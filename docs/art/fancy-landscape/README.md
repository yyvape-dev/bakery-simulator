# 明るく可愛い絵本の庭

2026-10-20。外景の色が淡く、左側の白樺と木立が不気味に見えるという指摘を受けて再制作。油絵の重ね塗り・筆触を残し、鮮やかな春の緑、コーラルピンクの花、赤いリンゴ、蜂蜜色の小道に変更した。

細長く枝垂れる白樺は使わず、短い幹と丸い樹冠のリンゴ・花木に置換。左側を密な列にせず、店舗を囲む小さな庭のまとまりに配置した。草花を大きくし、石はクリーム色と赤いキノコの明るい素材にした。灰色の道路も暖かなクリーム色の石畳へ置換。砂と石畳は素材の不透明度を72%から94%へ上げた。草地は鮮やかな緑の下地に筆跡を60%で重ね、細かな明暗が店舗より目立たないよう調整した。

店舗・室内・扉3種類×4方向・動物客8種・保存・営業は維持する。新旧セーブとも景色だけを更新する。外の配置や通行機能は追加しない。

生成元：`terrain-atlas.png`（草地・砂・石畳の3列）、`scenery-atlas.png`（上62%：丸いリンゴと花木、下38%：草花と苔石）。画像生成で一式を再制作。再構築：

```
node tools/art/pack_landscape.cjs docs/art/fancy-landscape blossom-tree
```

実行時は `assets/exterior/`。`birch-tree.webp` は旧版の資料との互換用に残すが、現行ゲームでは読み込まない。描画の位置は `exterior.js` で店舗寸法に追従する。
