# 店の外観と店主の見かけの大きさ

2026-10-19。四方に土・砂混じりの原っぱ、店の周囲に砂地、正面に歩道と道路を配置。入口までのアプローチ、道路の中央線・縁石・ガードレール・電柱と架線を追加した。正面は低い壁で店の輪郭を示し、内部を見渡せる表示を維持する。

扉は「木のガラス扉」「セージの扉」「アーチの扉」の3種類。メニュー → 設定 → お店の扉で無料切替し、保存・再読込に対応する。開いた扉と透明な開口を持ち、既存の入口位置に合わせる。

[外観と3種類の扉](review/index.html)。

配置と形を実装した後、画像生成で地面3素材と扉3種類のアトラスを制作。元画像は `terrain-atlas.png` と `door-atlas.png`。`node tools/art/pack_exterior_materials.cjs` で実行時WebP6枚へパックする。扉は正面画から店舗の斜めの面へ投影する。電柱・ガードレール・看板は共通座標で描く。

店主はノアより細いシルエットを補うため、基準表示の幅を20%、高さを10%大きくした。足元と当たり判定の変換、設備の接触計算を同じ表示寸法で更新する。人物の保存済みの体型スライダーは上書きせず、この基準に乗算する。経路の占有は1マスのまま。

外構は店舗の外側の景観。外で家具を配置する機能や道路での通行シミュレーションは追加していない。入店・退店は従来の入口セルへ接続し、配置・所持金・営業の進行を維持する。扉の選択だけ `room.entranceStyle` を追加し、不正／未設定の値は木の扉になる。

## 確認

`node tools/tests/exterior.cjs`：6素材、3扉の切替と保存、小画面・横画面、店舗・内装・所持金の非変更、足元固定、体型設定の維持、180分の製造と販売を確認。[結果](review/validation.json)。最初の180分で6件販売。

動かない地面・道路は画角ごとにキャッシュし、移動中の毎フレームで描き直さない。画像読み込み・増築・ズーム・画面サイズ変更で更新する。回帰確認は営業20項目／3営業日、描画438ケース、内装画面16項目が成功。
