# 主人公（店主）：採用第1案と4方向の歩行

2026-10-15。ユーザーの「おお、いいんじゃない」を受け、第1案を基準デザインとして保存。
顔・笑顔・低いまとめ髪・シュシュ・服装を維持し、4方向×待機・歩行2コマを制作した。

## デザインと制作元

- 顔・前髪のモチーフ：ユーザー提供の1枚目右側の成人女性。
- 背面のモチーフ：2枚目左側の同女性。低いお団子とクリーム色のシュシュ。
- 写真のクリーム色の袖と茶色のパンツを活かし、パン屋用のくすんだ緑のエプロンとクリーム色のポケットへ。
- 子ども・赤ちゃん・抱っこ紐・写真の背景はキャラクターへ取り込まない。
- ユーザーの元写真はリポジトリに含めていない。

`approved-v1.png` が会話で採用された4方向の立ち姿。待機コマにはこの画像を使い、別生成で置換しない。
`source-atlas.png` から第1歩行と背面の第2歩行を採取。前向きの第2歩行は足の交替が弱かったため、両足を接地した反対の踏み出しを `source-grounded.png` で作り直した。
画像生成と作画修正はimagegen、切出し・縮率合わせ・アトラス化はsharp。

## 寸法と検証

`owner.webp` は768×1024、256×256セルの3列×4行。行はY+、X+、Y−、X−、列は待機・第1歩行・第2歩行。
接地アンカー `[128.00010681152344,194.692138671875]`、タイルX投影 `[43.09983825683594,23.273902893066406]`、占有1×1を維持。
主人公の絵の高さは約104〜112px。tx=18では約43〜47px、ノアより少し背が高い。
`assembly.json` にソースの切出し範囲・接地位置・縮率、`assembly-report.json` に余白と0.5px未満のアンカー丸め誤差を記録。

```sh
node tools/art/pack_noah_study.cjs docs/art/owner-study/assembly.json
node tools/tests/noah-art.cjs --owner-study
node tools/tests/workflow.cjs --owner-study --noah-study
```

組立スクリプトは主人公とノアで共用。ノアを既定の組立方法で再出力し、既存WebPとバイト一致を確認した。
主人公の3画面サイズ×4方向×3コマ×3体型の108条件で接地原点・人物選択・保存復元・旧素材への切替を確認。
主人公とノアの候補を同時使用したworkflow20項目（3日営業、経路、途中保存、会計、家具移動／撤去、旧保存移行）に成功。
Godot 4.6.3 / Mesa llvmpipeで実描画した。スマホ実機は未確認。

生成画像のカメラは既存の固定投影への近似。描画原点の固定と、足裏の完全な物理接触は別。
歩行コマ間には手・前髪・服の微細な作画差が残るため、最終作画時にさらに統一する。
