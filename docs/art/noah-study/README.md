## 今回の判断

第3案の違和感は、写実的な毛の情報量、頬・胸・尾の重なりによる複雑な輪郭、大きな尾の張り出しにある。
白黒の面を広くし、胸毛・頬を少数の毛束へ、尾を体の近くへまとめた。青エプロン、クリームのポケット、白い額・口元、外へ流れる折れ耳、上まつ毛を継承。
背面は顔やポケットを流用せず、背中・交差する紐・結び目を描いた。

初回の生成は歩行2コマが同じ足の前進に寄ったため不採用。画面上の足の高低を指定して反対の接触ポーズを作り直し、全方向の第2歩行コマへ使用した。
`source-atlas.png` から待機と第1歩行、`source-opposite.png` から第2歩行を採取している。

**残る検討点**：小さな表示では長いまつ毛は数ピクセルにまとまる。耳をさらに三角形として読ませる余地がある。
毛の写実性は減ったが、丸い陰影による立体感はまだ残る。異なる生成元の歩行コマ間には頭・手・紐の細かな揺れがあり、最終作画では輪郭をさらに統一したい。
したがって本素材を「最適なデザイン」や最終完成として扱わない。比較画面とGodotの輪郭表示で、顔・耳・足の読み取りと可愛さを評価するための試作。

## 寸法・接地

`noah.webp` は768×1024の透過WebP。256×256セル、3列（待機・第1歩行・第2歩行）×4行。
行は0:Y+（正面左斜め）、1:X+（正面右斜め）、2:Y−（背面右斜め）、3:X−（背面左斜め）。
既存 `build_characters.py` の固定カメラと `geometry.json` / `index.html` の投影を参照。

- 接地アンカー：`[128.00010681152344,194.692138671875]`
- タイルX投影：`[43.09983825683594,23.273902893066406]`
- Godotの床：X=(x−y)×tx、Y=(x+y)×tx×0.54。
- 足元での拡縮。フットプリント・位置・経路・移動速度・保存バージョンは共通。
- セル内のキャラクター高さ：約96〜101px。通常のtx=18では約40〜42px高。

`assembly.json` は画像ごとの切出し範囲、足の接触面から測ったアンカー、縮率を記録。
**画像生成のカメラは近似であり、固定3Dモデルと同一の投影を数学的に保証しない。**
生成シートの等分だけでは1行目の足が切れるため、行境界を明示して切り出した。
アンカーの丸め誤差は各軸0.5px未満。足の前後移動による各コマの画像最下端の差は、接地原点の移動とは別。
自動テストは描画原点が動かないことを確認するもので、足裏の完全な物理接触やデザインの良さを証明するものではない。
