# 景色だけの拡大縮小と、絵本のようなUI

2026-10-19。店舗・原っぱ・道路だけを拡大縮小し、文字・ボタン・ウインドウの大きさを固定した。UIは生成した油彩の重ね塗りと色むら、木枠、葉・蔓・パステルの花で共通仕上げにした。

[画面と拡大表示](review/index.html)。

## 景色の操作

- キャンバス上のホイール／トラックパッド、2本指ピンチで45〜300%へ拡大縮小。ポインター／指の中心の景色を基準にする。
- 空いた場所をドラッグすると景色を移動。家具の移動や内装編集中のドラッグとは分ける。2本指操作に移ると未確定の編集をキャンセルし、ジェスチャーの指を離すまで購入などのクリックを抑える。
- 右上の「−／全体／＋」で倍率を変更。「全体」で100%と中央位置へ戻る。設定にも縮小・拡大・全体表示を置く。キャンバスが小さいときは右上を隠し、設定から操作できる。
- 倍率は従来の保存項目 `zoom` を利用。画面内の移動量は一時的で、再読み込み時は中央位置へ戻る。既存セーブの配置・体型・営業は維持する。

## 共通の絵本UI

HUD、営業・材料表示、通常のボタン、メニュー、スタッフ、商品・開発・完成、設定、収支、設備パネル、内装の素材と増築、店内の状態ラベルまで共通素材を使う。文字の背面は淡いクリーム色、選択・作業はセージ、注意は淡い桃色。花や蔓は操作を遮らない透明の飾りとして隅へ配置する。

画像生成元は `surface-atlas.png` と `ornament-atlas.png`。4面と四隅の飾りを `node tools/art/pack_storybook_ui.cjs` で実行時WebP8枚へパックする。`storybook.css` に仕上げを集約し、既存の操作や価格・担当などの処理を変えない。

## 検証

`node tools/tests/storybook-ui.cjs` でボタン、ホイールの焦点固定（実ブラウザーの座標丸めを含む1 CSS px未満）、実2本指ピンチ、HUDの寸法不変、保存と資産の維持、空き地のパンと全体表示、各ウインドウ・内装画面、320px・390px・横画面を確認。[結果](review/validation.json)。
