# 主人公・ノアの作業モーション試作

2026-10-15。既存の比較用キャラクターに4方向の作業を追加。主人公・ノアとも36コマ、合計72コマ。通常URLの旧素材は維持し、`?demo=motion` または各人物の `=study` で表示する。

| 実際の仕事 | 表示 |
| --- | --- |
| 仕入れ受取り | reach＋箱 |
| 仕込み | knead（生地入りの手描き素材） |
| 生地・パンの運搬 | carry＋実際に所持している生地／選択レシピのパン |
| オーブンへの出し入れ | reach＋生地／パン |
| 棚への陳列 | reach＋パン |
| 会計 | checkout＋受渡し側のコマだけ硬貨 |

焼成待ちは設備側の状態で、人物の独立モーションにはしない。待機・空手の歩行には既存12コマを使う。作業は2コマ、運搬は静止＋左右の歩行2コマ。歩幅は実移動距離、作業は225ms周期で切替。移動座標は既存75ms更新のままで、補間や滑らかな多コマ化は未実装。

`character-motion.js` は仕事・段階・所持品から表示のみを導出する。作業時は対象設備へ向き、設備が撤去されたらその場での作業を止める。仕事の所要時間、材料、会計、経路、保存形式は変更しない。素材読込みに失敗しても旧表示へ戻る。

## 制作・再構築

- `sources/` は画像生成元、`prompts.json` と `alternate-prompts.json` は実際の指示。ユーザーの元写真は含めない。
- `assembly.json` は切出し、接地点、縮尺、手元小物の位置。`node tools/art/pack_work_motions.cjs` で `assets/characters/actions/` を再構築する。`--init` は手調整を上書きするため通常使用しない。
- 生成画像の運搬歩行が同じ足になった箇所は別の4方向素材で修正。主人公の会計正面2方向のBコマは入替え、背面右のBコマは同方向の受渡し素材を使用。反転で方向を作っていない。
- セル256×256、接地アンカーと投影・占有は従来と共通。出力8枚のWebPは合計約392KB。

## 2026-10-15：手元と仕込み台の高さ

仕込み台を0.85マスへ下げ、仕込み中の手元を天板の高さへ補正。頭部の上側・足元と経路を固定し、奥側の手元の重なりと選択の逆写像も調整。[調整前後の8方向比較・192条件の結果・再出力手順](contact/README.md)。極小体型は変形量の制限により高さ差が残る。main未公開。

## 確認資料と限界（下記動画は高さ調整前）

- [ゲーム内30秒動画](game-actions.mp4)：通常タイマー・390×844で営業を録画。仕込み→運搬→会計→受渡しの静止画も同梱。
- [Godotでの比較動画](godot-actions.mp4)：両人物・設備・基準素材を並べた8秒。`godot --path tools/art/godot -- --owner --action=knead`。`--cycle-actions` で4種類を巡回する。Godotは検証用で、ゲーム本体の移行ではない。
- `node tools/tests/work-motions.cjs`：72セルの透過・はみ出し、距離同期、両者の担当入替と全作業、13件の販売、描画で資産やセーブを変えないこと、メニュー停止、素材欠損、対象撤去を確認。
- `node tools/tests/startup.cjs` の5ケース、比較素材使用の `workflow.cjs` の20ケース・3営業日も成功。
- **仕込み台の標準体型は上記で高さ調整済み**。他設備と極小体型の厳密な接触は未調整。生成コマ間の顔・輪郭にも微差がある。70〜130%の体型すべてで作業面へ接触する保証、IK、振向き補間、多コマ歩行はない。次の調整はゲーム内縮尺で手元と設備の高さを詰めること。
