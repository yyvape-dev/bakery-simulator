補正する帯ごとに元画像を切り出す処理では、各帯の透明な縁が別々に補間され、特に大きいノアの頭・首・腕へ細い横線が出ていた。元の1セル全体を描き、共有する画面上のピクセル境界で帯をクリップする方法へ変更。変形量0の描画が1枚描画と画素単位で一致することを、両人物・仕込み／受渡し／会計・4方向・A/B・DPR 1／2の96ケースで確認した。さらに、不透明なセルを実際に変形する54条件で境界のアルファが255を保つことを確認。修正前の描画へ戻すと同じテストで境界が192となり失敗することも確認した。

小物は人物の手の位置へ追従するが、人物の幅・高さ・全体倍率では変形しない。店舗ズームには追従する。仕込み素材に描き込まれた生地や家具の固定パンは、この小物描画の対象外。

人物本体を家具の前へ丸ごと移動する変更は行っていない。手を天板上へ再描画する既存の条件を共通関数にまとめ、小物も同じ条件で同じ深度へ描く。家具を移動中は、その家具向けの再描画を抑止する。

## 残る見た目と制限

- A/B間の顔・耳・袖・輪郭には素材由来の差が残る。今回、生成画像の再制作・頭部の貼替えはしていない。足元と頭部上側を動かす補正も追加していない。
- 小さい人物は設備の奥でほぼ隠れる場合がある。特に棚の背板、オーブン背面、低い補助板。常時透過・手前表示にはしていない。
- 既存の経路は設備を全周囲から利用する。オーブン側背面は受渡しトレーのままで、窯口への厳密な動線は未解決。表示だけで解決したとは扱わない。
- ステータスラベルが小さい人物の手元を隠す場面がある。レイアウトやラベルの優先順位の調整は残る。
- 2コマの切替・75msの移動粒度は維持。IK・各指先の独立接触・補間・Godot側の変更は今回の対象にしていない。

## 再現

Node.js、Playwright、sharp、`/usr/bin/chromium`、ffmpegが必要。Playwright用ffmpegが未導入なら `npx playwright install ffmpeg` で用意する。

```sh
node tools/art/review_work_motions.cjs --out /tmp/bakery-review-before --ref 976dda2
node tools/art/review_work_motions.cjs --out /tmp/bakery-review-after
node tools/tests/work-display.cjs
node tools/tests/work-motions.cjs
node tools/tests/equipment-contact.cjs
node tools/tests/work-contact.cjs
node tools/tests/workflow.cjs --owner-study --noah-study
node tools/tests/furniture.cjs --once
```

確認結果：描画288ケース＋横線の画素比較96ケース＋変形時の不透明性54ケース、72素材セル・実営業13件販売、設備接触139,968条件、仕込み接触31,104条件、営業20項目・3営業日、家具18項目が成功。接触の最大差は従来どおり約1.024 CSS px／約0.862 CSS px。

`--parallel` は6本の営業を別ブラウザーコンテキストで同時に録画する。ゲーム内タイマーの速度は変えない。負荷を抑える既定値は2本ずつ。

新しい出力先を指定し、過去資料を上書きしない。`--sheets-only` で固定比較だけを生成できる。従来の接触テストは自分の資料ディレクトリへ画像を再出力するため、過去の記録を保持する場合は実行後の差分を確認する。
