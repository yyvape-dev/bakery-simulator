# オーブン出し入れ・陳列・会計の接触調整

2026-10-18。PR #4／`art/work-motions` の続き。main未公開。

## 変更

- オーブン正面：手元から窯口へパン用の差し込み板（ピール）を伸ばす。生地を入れるときはA→Bで外側→内側、焼き上がり回収・陳列用の取出しは内側→外側。先端の高さは既存Blenderモデルの炉床上面1.085マス、正面方向は家具の回転に追従する。生地／選択中のパン画像は先端に描き、手元と二重表示しない。
- オーブン側面・背面：既存ゲームは周囲の全作業セルを使う。経路は変更せず、手元に受渡しトレーを表示する。レンガ壁へ穴を追加したり、窯口がない側へ差し込み板を通したりしない。**側面・背面は受渡し表示であり、その位置から窯内へ直接出し入れする厳密な接触を実現したものではない。**
- 陳列：パン棚の下段の高さ0.855マスを基準に、届く位置へ受渡しトレーを出す。パンは測定した手元に追従する。正面以外からの作業も従来どおり可能で、背板・側板に隠れる手元は手前へ重ねない。
- 会計：カウンター上面1.325マスを基準に、体型に合わせた会計トレーを表示。Bコマだけ硬貨を描く。主人公・ノアの掌位置をA/B別に測定し直し、特にノア正面の硬貨が逆側へ出る旧オフセットを修正した。
- 体型差：仕込みで実装した補助板の処理を共通化し、手元の縦横補正・高さと幅の調整・選択の逆写像を設備作業にも適用する。頭部の上側・足元・影・人物座標は固定。板やトレーの張り出しは作業者の1セル内。低いトレーは床上の位置で奥行きを並べる。
- 表示のみ：仕事・担当・所要時間・所持品・仕入れ・材料・売上・会計・保存・経路・占有を変更しない。所持していない生地の窯入れ表示や、運搬数0の陳列パン表示を抑止する。待機・移動・対象撤去・対象から離れたときには設備接触を表示しない。仕入れ受取りは今回の設備接触調整の対象外。

高さの制作元：`tools/art/build_furniture.py` のOven hearth slab（中心1.00＋厚さ.17/2）、Counter worktop（1.25＋.15/2）、`build_shelf.py` の下段パン配置基準.855。画像の再生成は行っていない。手元は `character-motion.js` の `equipmentHands`、対象条件・基準高さは `contactSpec`。
