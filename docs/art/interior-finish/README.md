# 壁・床の手描き調仕上げ

2026-10-19。初期店舗の配置だけでは旧デザインの壁床が残っていたため、床3素材・壁3素材を家具と同じ温かい手描き調へ更新。

[店舗の前後比較と素材一覧](review/index.html)。

- 木床：蜂蜜色の木目、幅のある板と3マスごとにずらした継ぎ目。
- クリームタイル：暖かい石灰石調、柔らかい色むらと控えめな目地。
- 石床：灰緑色の石目と鉱物の質感。
- 漆喰壁：鏝の塗り跡、木の腰板、見切りと巾木。従来の区画ごとの縦線を除去。
- 木壁：縦の木目と板継ぎ、上下の横桟。
- レンガ壁：テラコッタの色むらと千鳥の目地。

画像生成で共通アトラス1枚を制作。`material-atlas.png` は制作元、`prompt.txt` は指示。`node tools/art/pack_interior_materials.cjs` で256px WebP 6枚へパックする。実行時の追加転送量は合計45,754 bytes。床と壁の面に画像を投影し、目地・腰板・縁を共通描画する。

素材名・購入費・返金・床座標・壁の輪郭・高さ・出入口・経路・保存形式を維持。新規店舗と既存セーブの同じ素材に新しい見た目が適用される。画像読み込み後はゲームと素材選択の見本を再描画し、読み込み失敗時も色と構造を表示する。
