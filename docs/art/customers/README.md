# 汎用の動物客8種類

2026-10-19。うさぎ・黒うさぎ・暗い紫の鳥・白い鳥・茶とら猫・白猫・黒猫・シカを二足歩行の絵本調で制作し、従来の猫絵文字のお客さんを置き換えた。

[8種類の完成デザイン・4方向と歩行](review/index.html)。

基本4種のデザインは画像生成で制作。うさぎはセージのベストと小さな鞄、鳥はミントのスカーフ、猫は青緑のスカーフ、シカは青いベストを採用。うさぎ2色、鳥2色、猫3色は同じ基本シートから色違いをパックし、向きや歩行のシルエットを共有する。暗い毛色も表情と服の色が読めるようにする。

`*-source.png` は生成元。`node tools/art/pack_customers.cjs` で4方向×3コマ、256pxセル、足元アンカー128,200の768×1024 WebPへ組み立てる。耳・角・尾を含めて余白内に収め、生成シートの行境界は透明な行で分割する。`assembly.json` に採用サイズと縮尺を保存。実行時8枚は約600KB。

来店時に8種を順に選び、外見・方向・歩行の距離を既存のcustomerに保存。移動距離で3コマを切り替え、停止時は中央の立ち姿にする。4方向は個別画像で、左右反転しない。客の足元と家具の描画順を合わせる。既存セーブで外見が未設定ならうさぎを表示し、価格・予約・会計・経路・占有は維持する。

## 検証

`node tools/tests/customers.cjs`。8枚・96セルの透過／非空／欠けなし、4方向、描画の資産非変更、全8種の入店・製造と販売、来店途中の再読込を確認。360分で12件販売、8種・4方向を観測。[結果](review/validation.json)。

営業20項目／3営業日の回帰確認も成功。状態ラベルは客の実画像から頭・耳・角の位置を測り、従来の絵文字サイズの位置へ重ねないようにした。
