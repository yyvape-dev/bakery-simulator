# 来店・商品確保・レジ会計・退店

客は入口(5,9)から1人ずつ来店し、家具の占有全マスを避ける4近傍の最短経路で近い棚へ移動します。最短12ゲーム分の来客間隔を維持し、先客の退店まで次の入店を待ちます。

棚の通行可能な周囲マスに到着すると1個確保し、棚在庫から引きます。この時点では売上を増やしません。客はレジの空いた周囲へ歩き、会計担当が別の周囲マスに到着して会計作業を終えると、販売数・売上・所持金へ1個120円を一度だけ加算します。レジの周囲には2マス以上の到達可能な空きが必要です。

棚の正面のみには制限せず、客・スタッフともに周囲の空きマスでやりとりします。複数棚の在庫は共有12個です。会計後は商品を持って出口へ退店。売り切れ客は購入せず退店します。

各マス到着時に行き先を再計算し、設備移動・撤去に対応します。未会計の確保品は、レジが利用できなくなったり閉店したりすると返却します。棚が満杯なら完成品へ戻します。入口と客の現在・次のマスへの家具配置は拒否します。

一時停止・非表示中は客の移動と会計も停止。18:00以降は退店だけ進み、締めで未完了の来客を終了します。確定済みの販売は保持します。

客の段階・位置・次マス・棚ID・レジID・確保品・支払済み状態を、スタッフ・在庫・売上・所持金と同じv6セーブで保存します。旧v1〜v5の購入済み客を再び課金しません。

現在は仮表示の客1人を使用します。客層・新しい客素材・複数客の会計行列は今後のブラッシュアップです。店主とノアの仕事は `staff-workflow.md`、MVPの検証結果は `mvp-status.md` を参照してください。

経路と設備の作業面は仕切り壁の境界も判定し、出入口を通ります。増築後は新しい入口と店舗寸法を使い、家具を利用してから会計・退店する流れを維持します。
