# 店づくりの内装UIを統一

2026-10-13。床・壁・増築を旧ダイアログから、店舗を見ながら使う下部パネルへ移した。

## 各カテゴリの表示と操作

- 床：実際の描画と同じ素材見本、名称、1マス単価、選択状態。選択すると塗り替えを開始。タップで1マス、ドラッグで四角い範囲。左の「塗り解除」で止め、素材選択で再開する。
- 壁：設置／出入口／素材変更／撤去を一列で切り替える。素材見本・区画単価・方向・低い表示を同じパネルに置く。素材変更は壁本体を選択し、方向と出入口を保持する。
- 撤去：不要な素材選択を隠し、返金を説明。指を置いている間に対象区画と予定返金を表示する。
- 増築：現在面積、最大サイズ、横・奥の追加面積と価格を表示。選択時は緑色の追加マスを表示し、購入と区別する。「増築する」で確認後に支払う。取り消しでは資金も店舗も変更しない。
- 編集中：現在の操作、範囲、支払い・返金、無効理由を表示。確定後も直前の費用を確認できる。
- 戻る：指を離す前の変更を取り消し、通常営業へ戻す。編集画面はセーブからの再開時に復元しない。

右側の「戻る」は全カテゴリで統一。左側は家具＝回転、床＝塗り解除／床を塗る、壁＝方向変更、増築＝購入確認。枠の切り替えで回転と方向の表記が残らないようにした。

増築の緑色マスは表示用のプレビュー。選択だけでは面積・家具・経路・セーブ・資金を変更しない。奥の追加領域と、購入後の家具・床・スタッフの移動も整合させる。

既存の通路、作業面、重複、入口、資金、最大面積の判定を継続。素材を選ぶだけで課金しない。同じ床材には再課金しない。

## 画面全体の点検で直したもの

- 横向きで下部ボタンが画面外に隠れる問題。低い画面ではパネル内をスクロールでき、主ボタンを見える位置に置く。
- 壁から家具へ切り替えた後に残る方向ボタンの表記。
- 設定で拡縮した直後の保存。営業が止まっていても保存する。
- 営業終了後に使えない個別作業ボタン。締めは使える状態を維持する。
- 内装の旧モーダルと重複したメニュー入口、不要なCSSを撤去。
- 素材・壁操作・カテゴリの選択状態を見た目とアクセシビリティ属性の両方で示す。

## 検証範囲

Chromium：390×844、320×568、844×390。内装UI16項目と、営業20・内装23・家具18・基本UI9項目を確認する。合計86項目。

内装UIの検証は `tools/tests/interior-experience.cjs`。実際のタッチ入力と表示を使い、選択だけでは課金しないこと、確定前の見積り、取消、出入口の保持、返金、拡張、保存、画面の収まりを確認する。

公開ファイルはTLS検証付きで取得し、実装とバイト一致を確認して、取得したファイルでブラウザーの内装UI検証を行う。ブラウザーの直接HTTPS訪問・スマホ実機とは区別する。

## 今回の範囲と今後の機能

通常営業・設備詳細・店づくり・スタッフ・商品・経営・設定の入口と既存機能を点検した。床・壁・増築を含め、旧内装画面への遷移は残していない。

カメラのパン・ピンチ、コンボ、客層、新商品研究、ランク・報酬、最終アートは今回追加していない。未実装の操作・商品・目標を、使えるボタンとして表示していない。
