# 営業観察・設備詳細・店づくりUIの実装

2026-10-13。ユーザーが確認した3画面ラフを既存ゲームへ接続。

## 表示と導線

- 上部：営業日・時間、所持金。通常画面は店名を小さく表示し店舗を中心にする。
- 店舗の下：当日または前日の売上、利益、当日の来客、棚全体の在庫、焼成・材料状況。
- 通常の下部左右：セーブ／メニュー。
- メニュー：開店・停止・再開・締め、店づくり、スタッフ、商品、経営・収支、床・壁・増築、設定。
- 設備選択：本体の透過、名前、占有サイズ、実際の状態、関連する個別指示、担当確認、回転、撤去。下部左右は移動／戻る。
- 店づくり：家具／床／壁／増築を切り替える。家具に既存画像・価格・占有サイズを表示。床・壁・増築は既存処理へつながる設定画面を開く。下部左右は回転／戻る。
- 商品：現在のパンの単価、共有在庫、焼き上がり、当日の販売・売上。製造・陳列の個別指示は選択スタッフに出す。
- 設定：表示の拡縮、設備数、初期化。初期化は確認付き。

通常画面で購入一覧・編集・手動作業の全ボタンを常時出す構成を整理した。目標・コンボ・新商品研究・客層・ランクは未実装なので表示していない。

## 操作と営業の関係

メニュー・詳細ダイアログ・店づくり中は営業時間、スタッフ、客の移動を一時停止。終了時は既存の開店／停止状態に従って再開する。通常の設備選択だけでは営業を止めない。

家具の直接ドラッグは継続。選択情報を開く際、指を置いている間は表示領域を変更せず、ドラッグの基準位置を維持する。店づくりから既存家具を選ぶと設備詳細へ移る。

撤去は選択した家具を対象とし、確認後に既存の半額返金処理を実行する。キャンセルでは資金・家具・保存を変えない。

個別指示は現在の担当ロールに応じたスタッフへ出す。棚→陳列、レジ→会計、オーブン・調理台→製造。設備単位の専属割り当てではなく既存の優先指示で、スタッフは実際の経路と利用可能な設備に従って作業する。

棚在庫と焼成状態は既存の共有管理を正しく表示する。棚ごとに在庫があるかのような表示を作らない。

## 保存と既存機能

保存キー `bakery_web_v1` とsaveVersion 6を維持。表示用の画面・メニュー状態は保存しない。手動セーブは既存の保存処理を呼び出す。保存できなかった場合は成功と表示しない。

床・壁・家具・キャラの独立管理、複数マス、回転、衝突、作業面、通路判定、拡張、個別指示、製造→陳列→会計、日別収支を継続。
