# 商品開発・評価・飾り付け 初版

公開されている『ドラえもんのどら焼き屋さん物語』の材料選択、完成商品と評価の表示、飾り付け、戻る操作の構成を参考にする。実機操作や動画全編の検証はしていない。数値・レシピ・評価項目は本作の独自仕様。

メニュー → 商品一覧 → 商品を開発 → 生地の材料・具材を選択 → 試作 → 新商品完成！ → 評価と飾り付け → この商品を作る。商品一覧から開発済み商品の評価にも戻れる。店舗へ戻るボタンは常時表示。各画面を開いている間は営業・スタッフ作業を一時停止。

## 実装

- 小麦粉を共通のベースに、水／ミルクと、具材なし／バター／チョコ／チーズの8レシピ。定番パンは最初から使用可能。
- 試作費は新規開発時に一度だけ。再表示・材料選択・キャンセルでは費用なし。
- 味・香り・食感・見た目の4評価とA〜Cの総合評価。結果は材料から決まる。反復で無限強化しない。
- 木のプレート・緑のクロス・花は一度購入すると各レシピに適用可能。見た目評価と単価を加算。
- 商品価格を会計・売上・所持金に反映。原料は現行の共通材料（30円／5個）を継続。
- 商品切替は予約式。棚・完成品・焼成・生地・運搬・客の未払い商品がすべてなくなり、製造仕事が完了してから切替。待機中は次の製造を開始せず、回収・陳列・会計は継続。取消可能。
- 客が棚から取った時点の単価を保存し、会計時の再計算はしない。旧セーブの予約商品は120円。
- 開発・飾り付け費は収支の投資項目として営業利益とは別表示。日締め・再開・初期化に対応。
- 保存キー bakery_web_v1 を継続し、形式7へ。旧データの家具・在庫・スタッフを保持。未知のレシピ・飾りを除外。
- 商品プレビューと選択カードは独自のSVGイラスト。材料7点・飾り4点・パン8点を assets/product-art.js に収録。家具やキャラクターの既存素材は維持。

## 今回の範囲外

複数商品を棚別に同時販売、食材別仕入れ、客の嗜好／試食会、人気の経時変化、スタッフ能力による品質、最終厚塗り商品素材は未実装。評価は現在、価格と表示を通じて体験に反映され、来客数を増加させない。

## 画像での選択（2026-10-14）

材料・飾り付けを画像＋名前＋費用の2列カードに変更。選択中は緑の枠とチェック、aria-pressedで明示。未購入は購入費、購入済みはその状態と売価の加算を表示。生地材料・具材は試作への追加費を表示し、基本120円との合計を試作ボタンに表示する。商品一覧もパン画像を使用。

材料を変えると開発中の完成イメージが更新される。水／ミルクは焼き色、バター／チョコ／チーズはトッピングが異なる。皿／クロス／花はパンの下の別レイヤーとして表示。SVG素材は画面起動時に一度登録し、選択変更で再取得しない。表示のためのデータをセーブへ追加せず、保存形式7を継続。最終的な厚塗り商品アートは未実装。

商品・営業・基本画面の41項目を確認。画像が実際に描画されていること、選択状態とプレビューの一致、切替会計、費用の二重請求防止、320×568／844×390でのカードと戻る操作を含む。公開の確認では配信ファイルの一致を確認し、取得したファイルをChromiumで操作する。直接のHTTPSページ操作やスマホ実機操作は未検証。

## 開発完了の画面（2026-10-14）

新規レシピの開発に成功すると「新商品完成！」を表示。パン画像・商品名・評価・価格・4項目の品質を確認し、「飾り付けへ進む」から既存の設定画面に入る。450msの画像登場と星の演出を付け、動きを減らす設定では停止。処理の待ち時間は設けない。

レシピ登録・試作費の記録・保存は開発操作時に即時完了。演出中に閉じたり再読込したりしても開発済み状態を保持し、商品一覧から再び設定可能。開発済みの評価表示には完成演出も追加費用もなし。開発画面はパン在庫を追加せず、製造商品も自動変更しない。販売商品を選んだ後の仕込み・焼成・陳列は通常のスタッフ行動を継続。

新規完了の表示、画面内での一時停止、即時保存、在庫未生成、飾り付けへの遷移、既存商品の再表示、閉じる／再読込、動きを減らす設定、小画面のスクロールを商品検証に追加。
