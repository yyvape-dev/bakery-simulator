# 商品開発・評価・飾り付け 初版

公開されている『ドラえもんのどら焼き屋さん物語』の材料選択、完成商品と評価の表示、飾り付け、戻る操作の構成を参考にする。実機操作や動画全編の検証はしていない。数値・レシピ・評価項目は本作の独自仕様。

メニュー → 商品一覧 → 商品を開発 → 生地の材料・具材を選択 → 試作 → 評価と飾り付け → この商品を作る。商品一覧から開発済み商品の評価にも戻れる。店舗へ戻るボタンは常時表示。各画面を開いている間は営業・スタッフ作業を一時停止。

## 実装

- 小麦粉を共通のベースに、水／ミルクと、具材なし／バター／チョコ／チーズの8レシピ。定番パンは最初から使用可能。
- 試作費は新規開発時に一度だけ。再表示・材料選択・キャンセルでは費用なし。
- 味・香り・食感・見た目の4評価とA〜Cの総合評価。結果は材料から決まる。反復で無限強化しない。
- 木のプレート・緑のクロス・花は一度購入すると各レシピに適用可能。見た目評価と単価を加算。
- 商品価格を会計・売上・所持金に反映。原料は現行の共通材料（30円／5個）を継続。
- 商品切替は予約式。棚・完成品・焼成・生地・運搬・客の未払い商品がすべてなくなり、製造仕事が完了してから切替。待機中は次の製造を開始せず、回収・陳列・会計は継続。取消可能。
- 客が棚から取った時点の単価を保存し、会計時の再計算はしない。旧セーブの予約商品は120円。
- 開発・飾り付け費は収支の投資項目として営業利益とは別表示。日締め・再開・初期化に対応。
- 保存キー bakery_web_v1 を継続し、形式7へ。旧データの家具・在庫・スタッフを保持。未知のレシピ・飾りを除外。
- 商品プレビューは仮イラスト（絵文字とCSSの器・クロス）。家具やキャラクターの既存素材は維持。

## 今回の範囲外

複数商品を棚別に同時販売、食材別仕入れ、客の嗜好／試食会、人気の経時変化、スタッフ能力による品質、最終厚塗り商品素材は未実装。評価は現在、価格と表示を通じて体験に反映され、来客数を増加させない。
