# 店内の状態表示

2026-10-14。参考作の対象の近くに状態を表示する構成を手がかりに、パン屋の既存運営へ連動した独自表示を追加した。参考作の全仕様を再現したという意味ではない。

## 表示

- 店主・ノア：名前と、仕入れ・仕込み・生地運搬・窯入れ・回収・補充・会計・待機・指示待ち。
- 通路・設備・棚の空き・仕入れ資金の待ち：スタッフの実際の状態に応じて注意色で表示。特定できない原因を勝手に材料不足などへ置き換えない。
- パン棚：共有在庫。営業中の0個は「品切れ」、開店前などは「棚は空」。設備ごとの在庫があるかのような表示にはしない。
- 焼成：残り時間、回収待ち、陳列待ち。焼成と完成在庫は共有状態なので、「全体」と明記し、代表のオーブン付近に表示する。スタッフが仕入れなどへ移った後も、スタッフに「焼成中」と表示しない。
- 客：来店、商品を選ぶ、レジへ、会計待ち、購入済み、退店。会計が完了した状態だけを購入済みとする。
- 営業を停止した場合：進行中の仕事・焼成の停止を表示する。

文字と色の両方で状態を示す。色だけで判断させない。キャラの見た目の高さ・太さ、家具の回転と実際の移動位置に合わせて表示位置を更新する。

## 表示と操作

吹き出し同士の重なりを避け、必要なら短い線で対象につなぐ。店内領域の外へ出さない。最大6件、小さい領域では4件に絞り、会計待ちや問題の表示を優先する。

メニュー、店づくり、家具の選択・ドラッグ中は非表示。通常画面へ戻ると現在の状態で復元する。表示はタッチ入力を受け取らず、家具・キャラ本体の既存の選択判定を維持する。

状態表示は読取専用。仕事の割り当て、経路、在庫、料金、売上、保存形式を変更しない。保存データへ表示状態を追加せず、再開時に実状態から作り直す。
