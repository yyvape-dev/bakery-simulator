# 改訂MVP：キャラクターが働くパン屋

## 完了条件

店主と初期パートナーに個別の仕事指示を出せる店舗で、仕入れ → 製造 → 陳列 → 客の選択 → レジ会計 → 締め → 再投資が実際の移動・作業と連動して完了し、3営業日を継続して遊べること。

これ以前の「基礎MVP完了」は配置・来客・収支の土台についての区切り。キャラクターの基礎モデルと仕事の連携が未実装のため、この改訂MVPは未完了。

## モデルの契約

- 占有・経路判定は常に1×1マス。見た目の身長・太さ・全体縮尺を変えても占有マスと移動速度は変えない。
- 足元の接地点を共通原点にし、家具と同じカメラの角度・投影で作る。高さ・太さはモデル側、表示の縦横縮尺は描画側で独立調整できるようにする。
- 基礎モデル、4方向の表示、最低限の歩行・待機・作業表現をMVPに含める。厚塗りの最終仕上げは次の段階。
- 女性店主は茶髪とエプロン。ノアは黒白のボーダーコリーと青系エプロン、ルークは茶白と緑系エプロン。
- 初期パートナーをノアだけにするか、ノア・ルーク両方にするかは未確定。共通のモデル・行動の仕組みを用意し、人数変更に対応する。

## 仕事と操作の仕様案

個別指示は必須。通常はキャラクターごとの担当・優先順位に基づいて自動作業し、個別指示で仕入れ・製造・陳列・会計の優先作業を指定できる。毎回の移動先タップを必須にはしない。

- 仕入れ：材料購入と受け取り。MVPでは1種類の材料と取引先で成立させ、店外の探索マップは追加しない。
- 製造：材料を使い、調理台とオーブンへの到着・作業に連動してパンが完成する。
- 陳列：担当が完成品を受け取り、棚へ移動して到着・作業後に補充する。
- 会計：客が商品を選んでレジへ移動し、担当の会計完了時に売上を一度だけ確定する。棚到着だけで即時売上にはしない。
- すべての仕事を家具を避ける移動と接続する。設備の移動・撤去時は再探索または待機し、理由を表示する。

材料費の確定時点は仕入れに統一する。製造時の二重支出を防ぐ。旧セーブのパン・所持金を維持し、仕入れ前の材料に相当する移行分を新規購入と混同しない。

## 追加する動作テスト

- 材料なしから仕入れ・製造・陳列・会計・締めまでの一連作業が完了する。
- 各キャラクターへの個別指示と担当変更が反映され、同じ作業・設備・在庫を二重に確保しない。
- 設備移動・撤去、材料不足、満杯の棚、資金不足、通路変更で破綻しない。
- 移動中・製造中・運搬中・会計中の停止と再読み込みで材料・パン・所持金が増減し直さない。
- 高さ・太さ・表示縮尺を変えても1マス占有、足元の位置、タップ選択、前後関係を維持する。
- 3営業日で保存・締め・再投資と収支の整合を維持する。スマホ相当表示と実機検証は区別して報告する。

コンボ・客層・厚塗り仕上げは改訂MVPの後。複雑な探索、雇用・能力育成、複数客の行列は別途拡張とする。
