# パン屋経営シミュレーター：最終ゴールとMVPの境界

## 最終ゴール

相性のよい設備・商品を配置し、客とスタッフの動線を整えることで売上が伸び、その利益で店を育てる。
自由な店舗づくりと経営を結びつける「配置のパズル性」を、ゲームの中心にする。

この方針はユーザーが提示したカイロソフト作品の要素整理を、このパン屋の独自仕様へ落とし込むためのもの。特定作品の全仕様を実機確認したという意味ではなく、例示された名称・効果をそのまま採用するものでもない。

## 完成版へ向けた柱

1. 設備と商品の相性・専門コーナー：条件を満たす配置で魅力、需要、単価などが向上する。成立条件と効果はプレイヤーが判断できるように表示する。
2. 動線とレイアウト：棚・レジ・製造設備の距離や通路を工夫する楽しさ。コンボを詰め込むだけでなく、通行と接客のしやすさも考える構造にする。
3. 客層の解放と育成：店の成長に応じて異なる好み・予算・訪問頻度の客が増える。既存客にも成長の意味を持たせる。
4. 商品研究と設備投資：資金やポイントを使って商品・設備を強化し、次の利益と新しい配置の選択肢につなげる。
5. 店舗・地域の拡張：タイル管理を維持して店を広げ、必要に応じて周辺地域やフロアの拡張へ進む。
6. 目標とご褒美：売上・顧客数・規模などによる店舗ランク、新しい要素の解放、季節イベント、将来的なライバル店。

設備の自由配置、移動、90度回転、撤去、複数マス、衝突と通路の判定は維持する。店を固定の1枚絵にはしない。

## MVPのゴール（改訂）

店主と初期パートナーが働く店舗で3営業日程度を遊び、個別指示が可能で、仕入れ→製造→陳列→レジ会計→締め→再投資の流れが実際の移動・作業と連動して成立すること。
1マス占有と見た目の高さ・太さを分離した基礎モデルを含める。詳細は `mvp-definition.md`。
保存・操作・経営結果が信頼でき、配置を改善する意味を1つ体験できること。

## 基礎MVPの到達点

- 操作と保存：本体の選択、直接ドラッグ、営業状況の保存と1日の進行。実装済み。
- 来客の行動：家具を避けて棚へ歩き、到着時に購入し、退店する。実装済み。
- 収支の判断：売上・材料費・営業利益・設備投資・返金・所持金の増減を日別に表示。実装済み。
- 配置の手応え：近い棚で購入までの時間が短くなり、同じ補充方針で販売数が増えることを検証済み。
- 継続プレイ：新規店舗から3営業日を通し、日次の保存・締め・再投資・収支の整合を検証済み。詳細は `mvp-status.md`。

上記は配置・来客・収支の土台の到達点。改訂MVPでは、さらに基礎キャラクターと個別指示・仕事フローを実装・検証する。完了後にコンボ、客層、家具・キャラクターのビジュアル強化へ進む。

コンボの具体的な対象・効果量は未確定。複数のコンボ、複数客の行列、客層育成、商品研究、ランク、拡張、季節、ライバルを現在の工程へまとめて追加しない。
新しい素材や歩行スプライトの制作もMVPの進行を妨げない段階で判断する。

## 配置パズルの評価基準

- 配置を変える前に、成立条件や利益につながる理由を理解できるか。
- 動かした後に、購入までの時間や売上などの変化を確認できるか。
- 相性のよい設備を寄せることと、通路を確保することの両方に判断の余地があるか。
- ひとつの固定配置だけを強制せず、異なる店舗づくりが成立するか。
